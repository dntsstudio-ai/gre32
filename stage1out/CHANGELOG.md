# VAT Stage 1 Update

## Новые файлы (положить в js/)
- **vcoins.js** — VCoins система: баланс, магазин, игры (монетка, слоты, ракета), подарки
- **notifications.js** — Push-уведомления + in-app панель уведомлений
- **users_search.js** — Поиск пользователей + стена профиля
- **admin_panel.js** — Панель ролей + статистика сайта

## Изменённые файлы
- **core.js** — Новые роли: subber/previewer/editor/mixer, VCoins popup, расширенный navigate
- **app.js** — Подключены все новые модули
- **auth.js** — VCoins баланс в профиле, колокольчик уведомлений
- **config/config.js** — VCoins цены, новые роли DUB-in, новые автоачивки
- **css/style.css** — Все новые стили Stage 1
- **index.html** — Новые секции: shop, stats; sidebar с VCoins и статистикой
- **js/releases.js** — Кнопка подписки, VCoins за просмотр 18+ мин

## Firebase Rules (firestore.rules)
Скопируй в: Firebase Console → Firestore → Rules
- Новые роли (subber, previewer, editor, mixer) имеют доступ к DUB-in
- Стена профиля: читать могут все, писать — авторизованные
- releaseSubscribers — подписки на новые серии
- vcoinLog — история транзакций VCoins
- notifications — уведомления пользователя

## Что нового для пользователей

### 🪙 VCoins
- Баланс отображается в профиле и sidebar
- +10 VC за просмотр релиза 18+ минут
- +5 VC ежедневный вход
- Магазин: цветной ник (выбор цвета), префиксы [VIP/PRO/FAN/LEGEND]
- Дарить VCoins другим пользователям по нику

### 🎮 Мини-игры
- Монетка: орёл/решка, удваиваешь ставку
- Слоты: 3 символа, до 10× за тройку 7️⃣
- Ракета: множитель растёт, забери до взрыва

### 🔔 Уведомления
- Колокольчик в шапке, in-app панель
- Кнопка "Уведомлять о сериях" на каждом релизе
- Push-уведомления браузера (с разрешением)

### 🔍 Поиск пользователей
- Кнопка "Найти друзей" в профиле
- Поиск по нику или email

### 📝 Стена профиля
- Текст и фото на своей стене
- Другие пользователи могут писать
- Настройки: все / только подписчики / закрыта

### 🎨 Новые DUB-in роли
- Саббер, Превьюмейкер, Монтажёр, Сводчик — полный доступ к DUB-in

### 👑 Admin
- Список всех пользователей с ролями
- Статистика: онлайн, регистрации, время на сайте
- Настройка цен в магазине VCoins

### 🍪 Cookie баннер
- Красивый анимированный баннер при первом визите
